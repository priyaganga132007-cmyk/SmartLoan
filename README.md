# SmartLoan 🏦

## Intelligent Loan Eligibility & Risk Assessment System

SmartLoan is a web-based loan assessment system that helps users check their loan eligibility and understand their financial risk based on their income, loan amount, credit score, interest rate, and loan tenure.

## Features

- User name input
- Monthly income input
- Loan amount input
- Credit score input
- Interest rate input
- Loan tenure input
- Monthly EMI calculation
- Loan eligibility checking
- Risk level prediction
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask

## How It Works

1. User enters their financial details.
2. JavaScript collects the entered information.
3. The information is sent to the Flask backend.
4. Python calculates the monthly EMI.
5. The system checks loan eligibility.
6. A risk level is calculated.
7. The result is displayed on the webpage.
